# Windows 플레이 테스트 22 — 협동 패드 연결 복구

2026-09-11-villa-22 · Windows x86_64 · Godot 4.7.1 debug export

## 변경 내용

빌드 21 머리 모션은 사용자 자연스러움 확인 완료. 이번에는 현재 빌라 로컬 협동의 입력장치 대응을 보완했다.

- P2 지정 패드가 분리되면 공유 월드를 일시정지하고 연결 끊김 안내를 표시한다. 다른 패드의 분리는 무시한다.
- 재연결 시 새 장치 번호를 P2와 캐릭터 선택 패널에 함께 적용한다. 자동 재개하지 않고 Start 또는 계속하기로 재개한다.
- 지정 P2 패드 Start는 Esc와 같은 메뉴 우선순위로 일시정지/재개한다. Input Map은 바꾸지 않았다.
- 선택/완료 중에는 기존 화면을 보존한다. 연결이 끊겨도 P1은 메뉴 복구/재시작/메뉴 복귀를 사용할 수 있다.
- VillaCoop는 정지 중 입력을 받도록 ALWAYS, 실제 Level은 PAUSABLE로 명시했다. 공유 물리/배송은 정지하며 분할 카메라는 유지된다.
- 이전 미커밋 작업과 빌드는 보존했다. commit/push/공개 배포 없음.

## 검증 및 한계

검증은 Windows 실행 파일의 자동 합성 입력 및 연결 콜백 주입이다. 실물 USB/Bluetooth 패드 연결 해제 시험이 아니다. 장치별 드라이버/매핑/버튼 해제 동작은 사용자 확인이 필요하다.

빌라 협동에서 다른 장치 무시, 분리 시 정지, 정지 중 위치 유지, 번호 변경 재할당, Start 재개/열기, 잡은 택배 정지와 잡기 유지, 완료 화면 보존을 검사한다. 기존 전체 회귀와 협동 계단 운반도 실행한다. 최종 수치는 아래 기록한다.

## 플레이 확인 요청

1. 빌라 협동에서 P2 Start로 메뉴를 열고 닫는다.
2. P2가 상자를 들고 있을 때 패드를 분리하면 두 사람과 상자가 멈추는지 확인한다.
3. 재연결 후 Start/계속하기로 재개하고 P2 이동·시점·잡기/놓기가 되는지 확인한다.
4. 배송 진행을 유지한 채 두 집 완료/재시작을 확인한다.

온라인/다른 PC 연결 없음. 실물 패드 기종별, 장시간 및 다른 PC 성능은 미검증. 협동 오디오/성능은 후속.
재현: tools/Run-Godot.ps1 -Mode Export / BuildCoopVisual / BuildVisual.

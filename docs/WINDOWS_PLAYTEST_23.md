## 구현

기존 PrototypeLevel은 P1만 감시하여 P2의 발소리/점프/착지/잡기/놓기 소리가 없었다. 감시 로직을 기존 LevelAudio.update_player로 옮겨 P1/P2에 같은 조건을 적용한다. 각자의 이전 상태와 발소리 타이머/음성 풀을 분리했다.

협동에서 P1 동작 소리는 왼쪽, P2는 오른쪽으로 0.55만큼 팬을 적용한다. PCM 좌우 gain은 equal-power 방식이며 생성한 스테레오 클립은 재사용한다. 화면 기준 구분으로, 월드 거리/방향에 따른 3D 공간 음향은 아니다. 배송/복구/택배 충돌은 공통 모노 알림으로 유지한다. 기존 Master 볼륨을 따른다. 싱글에서는 기존 모노를 유지한다. 기존 절차적 소리를 재사용했고 새 음원 구매는 없다.

협동 성능 검사는 1280x720에서 두 사람 야외 / P1 야외·P2 실내 × 그림자 on/off 네 가지 300프레임 표본이다. 카메라/플레이어를 고정한 로컬 측정이며 목표 FPS나 최소 사양 보증이 아니다. 필요성이 확인된 경우에만 성능 관련 코드를 변경한다.

## 검증 구분

자동 검사는 실제 내보낸 Windows 실행 파일에서 합성 입력으로 P2 동작 이벤트를 검사하고 PCM 채널 크기를 비교한다. 소리의 청감은 직접 들은 검증이 아니며 사용자 확인 대기다. 최초 발소리 검사는 15프레임 이동이 발소리 간격보다 짧아 실패하여 45프레임으로 수정했다. 실물 패드 연결 해제/재연결도 여전히 미검증이다.

## 플레이 확인

1. 협동에서 P1/P2가 번갈아 걷고 점프하며 양쪽 소리 크기가 적절한지 확인한다.
2. P2 상자 잡기/놓기 소리와 두 사람 동시 운반 시 소리 과밀 여부를 확인한다.
3. 한 사람이 실내에 있고 다른 사람이 야외에 있을 때 화면이 끊기는지 확인한다.

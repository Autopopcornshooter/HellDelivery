# 빌라 실내 재구성 레퍼런스 — villa-11

후속 villa-12: 사용자 사진 피드백으로 벽 쪽 난간·손잡이는 제거하고 중앙 난간만 유지했다. 바닥·계단을 벽까지 연결했다. 아래 내용은 villa-11 제작 당시의 참고 기록이다.

사용자 요청: 트럭 글자 깨짐 수정, 레퍼런스를 찾아 현재 빌라 실내 재구성.

## 확인한 시각 자료

Coast Creative, **Staircase at Avalen** (Bude, Cornwall).
https://thecoastcreative.co.uk/case-studies/staircase-at-avalen/

원문 사례의 계단과 계단참 사진 두 장을 직접 확인했다.
- `Coast-Creative-Pip-Hambling-Bude-Avelen-staircase-web-soc-03.jpg`: 계단부터 계단참까지 이어지는 테라조, 가는 금속 수직 난간과 목재 손잡이, 벽에 둘러싸인 계단 공간.
- `Coast-Creative-Pip-Hambling-Bude-Avelen-staircase-web-soc-07.jpg`: 채광창, 밝은 천장과 벽, 층 경계를 이어 주는 난간, 문틀과 현관의 크기 관계.

사진은 `validation/villa-11/references`에 로컬 검토용으로 보관한다. 게임 텍스처나 배포 ZIP에는 포함하지 않는다. 사진 저작권은 원저작자에게 있다.

## 현재 맵에 적용한 해석

원본의 노란 벽이나 평면을 복제하지 않고 기존 빌라 게임 공간에 맞춰 해석했다.

| 기존 문제 | 변경 |
|---|---|
| 계단을 큰 상자 벽으로 둘러싼 느낌 | 층을 연결하는 난간, 벽 부착 손잡이, 계단참까지 연속된 석재 마감 |
| 파란 판을 붙인 가짜 창 | 벽을 실제로 나누고 유리·프레임·창턱을 갖춘 개구부 구성 |
| 계단참 뒤 빈 바닥과 건물 하부 개방 | 계단참을 벽까지 연장하고 하부 현관 전면·측면 연결 |
| 청록색 지붕이 그대로 천장에 노출 | 밝은 천장 안쪽 마감, 천장 몰딩과 매입 형태 조명 |
| 벽에서 떨어진 안내판과 검은 사각형 문 | 벽 부착 표지, 호수·문틀·손잡이·도어벨·발매트가 있는 현관 |
| 실내를 가리는 배송 판정 원기둥 | 같은 판정 영역을 유지하며 바닥 표식으로 시각화, 실내 높이에 맞춘 목표 문구 |

석재 무늬와 메시·표지는 프로젝트 내 코드로 제작했다. 기존 캐릭터·차량·City/Factory 에셋을 유지했다. 주거 분위기와 운반 여유를 함께 맞추는 것이 목표이며 실제 건축 시공 도면이나 규정 준수를 표현하는 자료는 아니다.

## 운반 검증에서 조정한 점

서쪽 독립 난간에 물건이 걸려 벽 부착 손잡이로 변경했다. 상부 계단은 서쪽 벽까지 넓히되 하부 기초를 같은 폭으로 늘리면 골목 진입 회전에 간섭하므로 기초 폭은 유지한다. 상부의 확장된 계단판은 벽에 접한다. 중앙·외측 난간은 보이는 막대에 대응하는 실제 충돌을 갖는다.

세대 문과 도어벨은 환경 소품이며 문 상호작용·NPC는 추가하지 않았다.

# Windows 플레이 테스트 14 — 빌라 두 집 배송

2026-09-10-villa-14 · Windows x86_64 · Godot 4.7.1 debug export

## 변경

기준 커밋 7cdd464 이후 현재 빌라의 왕복 배송 플레이를 확장했다. 메뉴의 ‘새 배송 노선 · 201호 + 202호’에서 주소가 있는 택배 2개를 각 집에 배달한다. 기존 기본 배송 1개 모드도 유지한다.

- Package의 5면 주소 스티커와 운반 중 HUD로 목적지를 표시한다. 사용자 제공 캐릭터·Factory Kit 택배·트럭·환경 에셋은 계속 사용한다.
- 주소가 다른 집은 물건을 접수하지 않고 목적지를 안내한다. 완료한 집에 잘못된 물건을 가져가도 거부한다.
- 각 집 1개 목표를 합산해 HUD·안내·일시정지 조작법·완료 화면에 2개를 표시한다. 순서와 무관하게 두 집 모두 완료해야 결과 화면을 연다.
- F5는 완료 배송을 보존하고 플레이어 및 남은 택배를 출발 위치로 복구한다. 재시작/다시 플레이는 두 집 전체를 초기화한다.
- 기존 맵을 상속한 VillaDeliveryRun 씬을 사용한다. 지형·팔·운반 물리·설정 저장 구현은 변경하지 않았다.
- 출발 안내판 수량을 2개로 맞추고 배송 표지를 같은 크기로 정리했다. 완료한 집의 떠 있는 글자는 숨겨 복귀 시 시야를 확보한다.
- 960×540 메뉴에서 모든 버튼이 보이도록 간격과 버튼 높이를 조정했다.

- BuildMultiRouteVisual: 별도 자동 이동/시점/잡기 입력으로 201호 운반→계단 내려오기→트럭 복귀→202호 운반→2/2 완료를 검사한다. 물건/플레이어 순간이동 없이 왕복한다. 초기 복귀 경로가 벽 모서리를 가로질러 멈춰, 벽 끝 바깥을 돌도록 검사 경유점을 수정했다. 실제 실패 기록은 validation/villa-14/BeforeReturnCornerFix.log에 보존한다.
- 기존 BuildVisual 및 BuildRouteVisual은 단일 배송 모드와 공유 UI/배송/캐릭터의 회귀 검사다.

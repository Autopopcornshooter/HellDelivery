## 변경

사용자가 villa-07 설정 유지 및 모델 누락 없음을 확인했다. 대표 레벨 점검표는 DEMO_READINESS.md에 정리했다.

- 공용 설정 화면에 그림자 켜기/끄기를 추가했다. 기본은 기존과 같은 켜짐이다.
- 빌라 방향광에 즉시 반영하며 설정 파일에 저장한다. 기존 파일에 항목이 없으면 켜짐으로 읽는다. 기본값 복원도 켜짐이다.
- 메뉴와 일시정지에서 같은 설정 화면을 사용한다. 720p에서 뒤로 버튼까지 표시되도록 항목 간격을 조정했다.
- 캐릭터·팔·환경 에셋·물리·배송 경로는 유지했다.
- 현재 PC의 고정 장면 프레임 간격을 두 그림자 상태에서 각각 600프레임 수집하는 Performance 모드를 추가했다. 실제 GPU 작업 시간이나 최소 사양 판정은 아니다.

## 검증과 한계

- BuildVisual 회귀 109개 통과: 그림자 즉시 on/off와 720p 설정 버튼 영역 확인 포함.
- SettingsWrite 1개 / 별도 프로세스 SettingsRead 8개 통과: 그림자 설정 복원 추가.
- 720p 설정 화면을 렌더링해 그림자 항목과 뒤로 버튼의 표시 확인.
- 병렬 BuildRouteVisual 한 번에서 계단 접촉으로 택배 잡기가 풀려 완료 검사 실패. RouteContactFailure.*에 보존했다. 실패를 통과로 바꾸지 않는다. 단독 재검증 및 성능 결과는 아래 인수 기록 참고.
- 알려진 좁은 계단/코너의 물건 접촉으로 잡기가 풀릴 수 있다. 다시 잡거나 F5 복구 가능. 이번에는 해당 물리값을 바꾸지 않았다.
- 사람의 새 빌드 직접 플레이, 다른 PC/GPU·장시간 플레이는 미검증. 현재 측정만으로 프레임 향상률이나 최소 사양을 확정하지 않는다.

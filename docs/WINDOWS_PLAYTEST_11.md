# Windows 플레이 테스트 11 — 트럭 한글 복구·빌라 실내 재구성

2026-09-10-villa-11 · Windows x86_64 · Godot 4.7.1 debug export

## 변경

- 트럭 한글 원문이 지난 PowerShell 편집에서 잘못 디코딩되어 저장된 문제를 수정했다. `HELL DELIVERY / 언덕마을 배송` 복원, 차체와 떨어진 표기판으로 배치했다.
- UTF-8 명시 입출력 규칙을 CLAUDE.md에 남기고 export 전에 엄격한 UTF-8 검사 및 대체 문자 검출을 수행한다. 이미 유효한 UTF-8로 저장된 잘못된 문구는 인코딩 검사만으로 찾을 수 없으므로 실제 트럭 문자열 회귀 검사와 화면 검토도 수행한다.
- 레퍼런스는 VILLA_INTERIOR_REFERENCES.md에 기록했다. 실제 주거 계단 사진을 확인하고 연속 석재·금속 난간·목재 손잡이·밝은 천장·채광창 구성을 현재 맵에 적용했다.
- VillaInterior.gd가 실내 구조와 마감을 담당한다. 기존 임시 실내 표지·검은 판 창·현관 장식·청록색 천장 안쪽 마감을 정리했다.
- 계단참을 북쪽 벽까지 확장하고 창에 실제 개구부·유리·틀·창턱을 만들었다. 계단실 전면 하부도 현관 전실로 연결했다.
- 계단·복도에 미세한 석재 무늬, 벽 하단 도장·걸레받이, 흰 천장·몰딩·조명을 통일했다.
- 호수 표기·문틀·패널·손잡이·도어벨·발매트·주민 게시판을 배치했다. 문과 도어벨은 소품이다.
- 배송 마커의 원기둥 시각화를 바닥 표식으로 낮추고 목표 문구를 천장 아래로 조정했다. 배송 판정 체적·목표 수·완료 로직은 유지한다.
- 기존 캐릭터 18종·트럭·배경 건물·택배 에셋과 설정을 유지한다. 새 유료 에셋·온라인 기능·차량 운전은 추가하지 않는다.

## 실행과 확인

`builds/HellDelivery-2026-09-10-villa-11.zip` 전체 압축 해제 후 `HellDelivery.exe` 실행. PCK를 같은 폴더에 둔다.

사용자 확인 목록:
1. 트럭의 ‘언덕마을 배송’ 문구가 가까이·멀리서 깨짐 없이 보이는지.
2. 계단실이 주거 건물 내부처럼 보이고 입구·계단참·위층 복도가 자연스럽게 이어지는지.
3. 난간을 따라 택배를 운반할 때 걸림이나 놓침이 있는지.
4. 창 채광·벽·조명 밝기와 바닥 무늬가 과하거나 어색하지 않은지.
5. 101호 배송 표식·완료·재시작·메뉴 복귀가 정상인지.

WASD 이동, 마우스 시점, 왼쪽 마우스 유지 운반, Shift 달리기, Space 점프, F5 복구, R 재시작, Esc 메뉴.

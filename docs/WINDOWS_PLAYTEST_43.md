## 변경
정상 완료와 두 사람 합의로 마무리한 주문을 방 기록으로 집계한다. 종료 주문 수, 전량 완료 수, 실제 배송 수/목표 수, 종료한 주문들의 시간 합계를 표시한다. 결과 화면에 누적 실적을 추가하고 대기실의 방 기록 버튼에서 최신순 최근 5건(주문명/배송 수/시간/완료 또는 부분 종료)을 확인한다. Esc 또는 돌아가기 버튼으로 대기실에 복귀한다. 새 주문 시작 시 기록 화면을 정리한다.

호스트 권위 결과에서 집계하며 기존 세대/finished 검사로 같은 결과를 중복 집계하지 않는다. 대기실 상태 RPC에 기록을 포함해 재접속한 참가자에게 같은 기록을 보낸다. 최근 5건만 유지하지만 누적 합계는 방 전체 기록이다. 프로토콜 43, 양쪽 빌드 43 필요.

호스트가 방을 닫으면 초기화한다. 영구 저장이나 개인 기록이 아니다. 취소, 재시작, 연결 끊김으로 중단한 주문은 기록하지 않는다. 0개 배송 합의 종료는 주문 1건/배송 0개로 집계한다. 부분 결과 HUD도 실제 배송 수를 사용하도록 정리했다. 미배송 개수를 완료로 올리지 않는다.

## 플레이 흐름
온라인 플레이 중 Esc 메뉴의 '현재 기록으로 주문 마무리'를 어느 쪽이든 선택한다. 요청자는 동의 상태이며 상대도 동의해야 종료한다. 한쪽이 계속하기/요청 취소 또는 Esc를 누르면 주문을 유지하고 메뉴로 돌아간다. 메뉴의 계속하기로 플레이를 재개한다. 확인 화면 중에도 세계 물리와 시간은 계속되며 로컬 입력은 중립 상태다.

동의한 경우 현재 배송 수·시간·호수별 기록을 결과로 표시한다. 예를 들어 1/2개 배송에서 종료하면 1/2개 기록으로 남으며 미배송 1개는 완료로 바뀌지 않는다. 완료한 택배가 없다면 0개 결과와 다시 도전 안내를 표시한다. 결과에서 같은 주문 재시작 또는 다음 주문 준비로 연결하고, 대기실에 돌아가 주문과 캐릭터를 바꿀 수 있다. 방은 유지한다.

결과를 표시할 때 택배 물리와 추가 배송 판정을 닫아 뒤늦은 배송으로 기록이 변하지 않게 한다. 다음 주문은 새 월드에서 정상 판정을 다시 시작한다. 기존 정상 완료도 같은 결과 표시와 정리 경로를 사용한다.

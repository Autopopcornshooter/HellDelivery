# HellDelivery — 온라인 2인 테스트 빌드 30

2026-09-11-villa-30 · Windows x86_64

ZIP 전체 압축 해제 후 HellDelivery.exe 실행. PCK와 라이선스를 같은 폴더에 유지하세요. Godot 설치 불필요. 기존 싱글/분할 화면 메뉴도 있습니다.

## 두 사람이 접속하기

1. 두 PC에서 같은 빌드를 실행하고 필요하면 메인 메뉴의 캐릭터를 선택합니다.
2. 호스트: 온라인 협동 → 방 만들기. 기본 UDP 포트는 27926입니다.
3. 참가자: 온라인 협동 → 호스트의 IP 주소와 같은 포트 입력 → IP로 참가.
4. 대기실에서 서로의 캐릭터를 확인하고 화살표로 내 캐릭터를 선택합니다. 캐릭터를 바꾸면 내 준비가 해제됩니다.
5. 각자 준비하기 → 둘 다 준비 완료이면 호스트가 배송 시작. 각자 전체 화면으로 같은 빌라에서 시작합니다. 호스트=P1, 참가자=P2.

같은 PC 두 번 실행 테스트에서는 127.0.0.1을 사용합니다. 다른 PC에서는 호스트 화면에 표시된 LAN IP를 사용하세요. 다른 집에서 접속할 때 LAN IP는 사용할 수 없습니다. 호스트의 외부 접속 주소와 UDP 포트 접근이 필요합니다. Windows 방화벽 안내가 나오면 사용하려는 네트워크에서 실행 파일의 통신을 허용해야 합니다. 공유기/NAT 자동 설정과 Steam 중계는 구현되지 않았습니다.
[Godot 직접 접속 안내](https://docs.godotengine.org/en/stable/tutorials/networking/high_level_multiplayer.html#hosting-considerations)

## 조작

두 PC 모두 WASD 이동 / 마우스 시점 / 왼쪽 버튼 유지 잡기 / 버튼 해제 놓기 / Space 점프 / Shift 달리기.
201호와 202호에 주소가 맞는 택배를 배송하세요. 같은 상자를 두 사람이 함께 잡을 수 있습니다.
Esc 메뉴는 내 입력만 멈추며 상대 플레이는 계속됩니다. 호스트만 F5 두 사람·미배송 택배 복구, R 전체 재시작을 실행할 수 있습니다. 복구는 완료한 배송을 유지합니다.
완료 후 호스트가 함께 대기실로 버튼을 누르면 연결을 유지한 채 캐릭터 변경과 다시 준비가 가능합니다. 바로 재시작도 가능합니다. 메인 메뉴 버튼은 연결을 종료합니다. 누군가 나가면 상대에게 종료 안내가 나오며 새 방을 만들거나 다시 참가할 수 있습니다.

## 이번 확인 요청

- 두 PC에서 접속하고 서로의 캐릭터/머리 움직임이 보이는지.
- 각자 잡기·놓기와 공동 운반이 자연스러운지.
- 계단을 통과해 두 집 배송 → 양쪽 완료 → 재시작이 되는지.
- 한쪽이 메뉴로 나간 뒤 안내와 재접속이 정상인지.

실제 두 PC/인터넷 지연 검증은 아직 하지 않았습니다. 참가자 이동은 호스트 응답을 따르므로 지연이 큰 연결에서는 늦게 느껴질 수 있습니다. 끼임/분실은 호스트 F5로 복구하세요. 호스트 이전/세션 진행 저장/온라인 게임패드 지원은 이번 범위 밖입니다.

# HellDelivery — 전체 배송 1~4인 테스트 빌드 48

2026-09-11-villa-48 · Windows x86_64

ZIP 전체를 압축 해제한 뒤 HellDelivery.exe를 실행하세요. PCK와 licenses 폴더를 함께 유지하세요. Godot 설치는 필요 없습니다. 새 **전체 배송**은 혼자 또는 최대 4명이 플레이합니다. 기존 싱글/로컬 2인/빌라 온라인 연습도 제공합니다.

## 전체 배송 시작

전체 배송 → 방 만들기 → 주문/캐릭터 선택 → 준비하기 → 배송 시작. 혼자도 시작할 수 있으며 동료는 같은 전체 배송 메뉴에서 IP로 참가합니다. 45kg 공동 주문은 두 사람 이상으로 도전하세요.

1. 물류센터 바닥의 택배를 마우스로 잡아 열린 트럭 뒤 경사로로 직접 싣습니다. 택배와 사람이 문에 걸리지 않도록 옆으로 비킨 뒤 **E**로 화물 문을 닫으세요.
2. 트럭 가까이서 **F**로 탑승합니다. 첫 탑승자가 운전석, 이후 세 명은 동승석입니다. **W/S 전진·후진, A/D 조향, Space 브레이크**로 앞쪽 빌라의 노란 주차 구역까지 운전합니다.
3. 정차 후 F로 내리고 트럭 뒤 E로 문을 엽니다. 택배를 직접 꺼내 왼쪽 골목·실내 계단을 거쳐 **2층 201/202호**에 배달합니다. 목적지는 상자 주소와 Tab 목록을 따릅니다.
4. 결과에서 등급/점수/상태를 확인하고 같은 주문 재시작 또는 대기실의 다음 주문/3연속 코스로 이어갑니다.

문이 열리면 주행 중 택배가 빠질 수 있습니다. 강한 충격은 택배/차량 상태를 낮춥니다. 택배 파손·분실, 제한 시간 초과, 차량 상태 0은 실패/부분 결과에 반영됩니다. 일반 8분, 다건/공동 12분, 혼합 11분입니다. **F5 전체 복구는 상태를 회복시키지 않으며 회당 50점 감점**합니다. Esc 개인 복구, 호스트 R 재시작도 사용할 수 있습니다. 점수는 현재 방의 기록이며 영구 화폐가 아닙니다.

## 접속과 준비

1. 모두 같은 빌드 48과 같은 모드를 실행합니다. 호스트는 전체 배송 또는 빌라 연습 · 온라인 협동 → 방 만들기를 선택합니다. 기본 UDP 포트는 27926입니다.
2. 참가자는 호스트의 IP와 같은 포트로 참가합니다. 호스트가 대기실에 있을 때 최대 3명이 참가할 수 있습니다.
3. P1은 호스트, P2~P4는 참가자입니다. 내 캐릭터를 화살표로 고르고 준비하기를 누르세요. 현재 참가자 전원이 준비하면 호스트가 배송 시작을 누릅니다. 빈 자리는 준비 대상이 아닙니다.
4. 호스트가 주문을 바꾸거나 참가자가 들어오고 나가면 전원 다시 준비합니다. 캐릭터 변경은 내 준비를 해제합니다.

같은 PC에서 여러 번 실행할 때만 127.0.0.1을 사용합니다. 다른 PC에서는 호스트가 복사한 LAN 주소를 사용하세요. IP:포트 붙여넣기와 Enter 참가를 지원합니다. IPv6는 [::1]:27926 형식입니다. 성공한 주소와 포트는 저장됩니다.

다른 집에서 접속하려면 호스트의 외부 접속 주소와 UDP 포트 접근이 필요합니다. Windows 방화벽 안내가 나오면 사용하는 네트워크에서 통신을 허용하세요. 공유기 자동 설정/Steam 친구 초대·중계는 아직 없습니다. 배송 중에는 새 참가를 거절하므로 호스트가 대기실로 돌아온 뒤 참가하세요.

## 조작과 배송

| 입력 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 시점 |
| 왼쪽 버튼 유지 / 해제 | 잡기 / 놓기 |
| Space / Shift | 점프 / 달리기 |
| Tab 유지 | 택배 목적지·무게·운반자·직선 거리 목록 |
| G | 잡은 택배 운반 도움 요청 / 취소 |
| Esc | 내 메뉴·설정·조작법·개인 복구 |
| F5 (호스트) | 모든 사람과 미배송 물건 복구, 완료 배송 유지 |
| R (호스트) | 현재 주문 전체 재시작 |

택배 주소에 맞춰 빌라 2층 201호/202호 현관으로 배송합니다. 같은 상자를 여러 명이 함께 잡을 수 있습니다. 동료 표식은 거리·방향·높이 차를 보여주며 가까이 붙으면 숨깁니다. G 요청은 함께 잡기/배송 완료/20초 후 사라집니다. 요청 후 잠깐 놓아도 표시가 물건을 따라갑니다.

Esc → 내 위치만 복구는 다른 사람의 위치·잡기와 완료 배송을 유지합니다. 메뉴·설정과 Alt+Tab은 내 입력만 멈추고 잡은 물건을 놓습니다. 다른 사람의 게임은 계속됩니다. 창으로 돌아온 뒤 계속하기 또는 Esc로 재개하세요. 화면/FOV/감도/음량/그림자는 내 PC에 적용하고 저장합니다.

## 주문과 다음 배송

| 주문 | 배송 구성 |
|---|---|
| 일반 | 15kg 2개 |
| 다건 | 15kg 4개 |
| 공동 운반 | 45kg 2개 |
| 혼합 | 201호 15kg 2개 + 202호 45kg 1개 |
| 3연속 코스 | 일반 → 혼합 → 공동 운반, 총 7개 |

결과에서 호스트가 다음 주문 준비를 누르면 같은 방 대기실로 돌아갑니다. 코스는 다음 순서가 자동 선택되며 매번 전원이 다시 준비합니다. 마지막은 총 배송 수와 완료한 주문의 합산 시간을 보여줍니다. 완료된 코스 순서는 결과에서 다시 실행할 수 없습니다.

중간에 다른 주문으로 넘어가려면 Esc → 현재 기록으로 주문 마무리 → 현재 참가자 전원 동의 → 부분 배송 결과로 진행합니다. 한 명이라도 취소하면 배송을 계속합니다. 부분 종료는 코스도 종료합니다. 방 기록은 누적 실적과 최근 5건을 보여주고, 완료/합의 종료한 주문만 포함합니다.

## 퇴장과 재참가

대기실 퇴장은 남은 방을 유지하고 준비만 해제합니다. 배송/로딩 중 참가자가 나가면 남은 사람 전원이 같은 방 대기실로 돌아가 현재 주문을 다시 준비합니다. 중단된 주문은 초기화하고 이전에 완료한 코스 실적은 유지합니다. 빈 슬롯에 재참가할 수 있습니다. 호스트가 방을 닫으면 모두 연결 화면으로 돌아가며 방 기록과 코스는 초기화됩니다.

하단에 참가자의 왕복 지연을 표시합니다. 입력이 끊기면 호스트가 해당 인물만 안전 정지시키고 P번호를 알립니다. 참가자 이동은 호스트 응답을 따르므로 지연이 큰 연결에서는 반응이 늦게 느껴질 수 있습니다.

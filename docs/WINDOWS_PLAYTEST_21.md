## 구현

기존에는 팔 운반 자세만 시선을 따라갔고 머리 상하 추종은 없었다. 사용자 요청으로 실제 플레이 캐릭터의 head에 카메라 pitch 추종을 추가했다. P1 마우스와 P2 오른쪽 스틱 모두 같은 카메라 회전을 기준으로 한다.

- 머리만 정면 바인드 회전에서 계산해 누적 회전을 방지한다. 응답 12/s의 지수 보간으로 부드럽게 전환하며 ±55도로 제한한다.
- 정지·걷기·달리기·운반 여부와 무관하게 적용한다. reset/복구 시 정면으로 초기화한다.
- 몸통·카메라·입력·운반 물리와 캐릭터 미리보기는 유지한다. 자기 head는 기존 1인칭 cull 처리로 숨겨져 있고 상대 화면에서 보인다.
- 이전 미커밋 작업·빌드는 보존하고 commit/push/공개 배포하지 않았다.

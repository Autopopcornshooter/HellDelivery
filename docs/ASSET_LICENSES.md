# ASSET_LICENSES.md

이 문서는 프로젝트에서 사용하는 외부(비직접제작) Asset의 출처와 라이선스를 기록한다.

**역할**: "이 Asset을 실제로 써도 되는가"를 한눈에 확인하는 장부. 코드나 씬 파일에는 라이선스 정보를 남기지 않으므로, 외부 Asset을 하나라도 도입하면 반드시 이 문서에 먼저 기록한다.

---

## 정책 (T085A에서 확정)

MVP-1~v0.3.0까지는 "외부 Asset 다운로드 금지"였다. v0.4.0 데모의 아트 방향성 확정 단계(T085A)부터 아래 조건으로 완화한다.

**허용**:
- 직접 제작한 Blender 모델
- 상업 이용 가능한 CC0 또는 명확한 무료 라이선스 Asset

**필수 조건**:
- 서로 다른 스타일의 Asset을 무분별하게 혼합하지 않는다 — 색상·스케일·재질 톤을 통일한다.
- 로우폴리 또는 스타일라이즈드 물류/도시 환경 방향을 유지한다(아래 "아트 방향성" 참고).
- 출처와 라이선스를 이 문서에 기록하지 않은 Asset은 사용하지 않는다.

**여전히 금지**: 라이선스가 불명확한 Asset, 상업 이용이 제한된 Asset, 이 프로젝트의 로우폴리/스타일라이즈드 방향과 크게 어긋나는 사실적(Photorealistic) Asset.

## 아트 방향성 (T085A에서 확정)

- **스타일**: 스타일라이즈드 로우폴리. 약간 과장된 도시형 물류 배송 현장.
- **원칙**: "예뻐 보이는 것"보다 "즉시 이해되는 것" 우선 — 짧은 Steam 데모에서 한눈에 읽히는 실루엣과 색상 대비를 유지한다.
- **구역별 색 규칙**:
  | 구역 | 색 | 적용 예 |
  |---|---|---|
  | 트럭/출발 구역 | 따뜻한 색(주황·크림) | `DeliveryTruck` 적재함(주황)·운전석(크림) |
  | 배송 경로(중립 구간) | 중립적 도시/창고 색 | 기존 바닥·계단·경사로·벽 재질(무채색 계열, 무변경) |
  | 위험/주의 구역 | 노랑·검정 계열 강조 | `HazardStack`(장애물 크레이트 더미, 노란 계열), 경고 표지판 |
  | 배송 목표 구역 | 채도 높은 강조색 | `DeliveryBuilding`(청록 계열, 기존 `DeliveryZone` Pulse 색상과 통일), `EntranceMat` |
  | 상호작용 가능한 물리 오브젝트 | 주변보다 읽기 쉬운 색상 | 기존 `PhysicsBarrel`(갈색)/`PhysicsCrate`(갈색)/`SmallPhysicsBox`(밝은 회색) — T085A에서는 값을 바꾸지 않았고, 이미 주변 무채색 지형과 대비되는 색이라 별도 조정 없이 채택했다. Package는 T085B에서 카드보드색 재질과 테이프·라벨·상하 표시를 추가해 장식 박스와 더 명확히 구분되도록 했다. |

## T085B 조명·재질 보강

- `DirectionalLight3D`를 낮은 각도(X축 -50°)로 기울여 늦은 오후 톤(`Color(1, 0.85, 0.65)`)의 지향광 + 그림자를 적용했다.
- `WorldEnvironment`에 웜톤 Ambient, 옅은 원거리 Fog, Filmic Tonemap, 약한 Glow(`intensity=0.35`, 과도한 Bloom 금지 준수), 약한 SSAO를 추가했다.
- `DeliveryBuilding`에 청록색 `AccentLight`(`OmniLight3D`), 트럭 적재함 내부에 따뜻한 색 `CargoLight`(`OmniLight3D`)를 추가해 각각 "최종 목적지"와 "Package 가독성"을 강조했다.
- `HazardStackLeft`/`Right`에 검정 경고 스트라이프를 추가해 "위험/주의 구간=노랑+검정" 색 규칙을 완성했다.

## 변경
잡고 있는 택배에 G로 운반 도움 요청/취소. 요청자는 전송 안내, 동료는 해당 택배의 위치/방향/거리와 같은 상자 잡기 안내를 본다. 택배 이동을 추적하며 화면 밖/뒤쪽은 가장자리 화살표, 높이 차는 위쪽/아래쪽을 표시한다. 목적지까지 길찾기가 아니라 택배까지 직선 안내다. 기존 동료 표식과 배송 목록의 겹침을 줄이기 위해 요청 표식을 우선 표시한다.

호스트가 요청자의 실제 held_grabbable를 확인하며 택배만 요청 가능하다. 클라이언트가 임의 대상 경로를 지정하지 않는다. 세대 번호로 이전 주문 요청을 거부한다. 20초 만료는 호스트 시계를 사용한다. 잠깐 놓아도 택배를 따라가며 공동 잡기/배송/시간 만료 시 자동 종료한다. 메뉴/목록에서는 위치 표식을 숨기고 결과/새 주문/연결 종료에서는 요청 상태를 정리한다. 입력과 네트워크 폴링은 계속된다.

프로토콜 45: 양쪽 빌드 45 필요. 기존 택배 힘/무게/잡기 규칙과 에셋을 사용한다. 싱글/분할 화면에는 새 요청 입력을 추가하지 않는다. commit/push 없음.

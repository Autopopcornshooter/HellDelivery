## 변경

- 한 집 배송 후 남은 상자가 트럭에 있으면 해당 주소 택배를 가지러 돌아가도록 안내한다. 상자가 중간에 옮겨져 있으면 재잡기/F5를 안내한다. 들고 있는 동안은 해당 주소를 표시한다.
- 완료한 구역만 차분한 색으로 바뀌고 바닥에 주소별 완료 표시가 남는다. 미배송 구역의 색은 유지한다. 시야를 가리는 완료 구역 공중 글자는 계속 숨긴다.
- 결과 화면에 실제 배송 순서와 각 배송 시점의 플레이 경과 시간을 표시한다. F5는 내역을 보존하고 재시작은 초기화한다. 영구 저장·점수·제한 시간은 추가하지 않았다.
- 밝은 실내 벽/야외에서도 목표·진행·안내·알림을 읽도록 어두운 배경을 적용했다. 오배송 포함 알림을 2.5초간 표시한다.
- 기존 맵·제공 에셋·캐릭터·운반 물리·설정은 재사용한다. 기본 1개 배송 모드도 유지한다.

추가 검사: 부분 완료 후 남은 주소 안내, 상자가 옮겨졌을 때 안내 전환, 구역별 완료 표시/색 독립성, 실제 배송 순서의 결과 내역, 복구·중복 판정 시 내역 유지, 재시작 초기화. 초기 실행에서 변수 이름 중복 파싱 오류를 수정했고, 캡처에서 바닥 완료 글자가 보이지 않는 문제를 발견했다. 높이/방향을 정리하고, 기존 실내 마감의 지연 호출이 바닥 글자까지 공중으로 옮기는 원인을 수정했다. 공중 안내 글자에만 마감을 적용하며 바닥 높이 회귀 검사를 추가했다.

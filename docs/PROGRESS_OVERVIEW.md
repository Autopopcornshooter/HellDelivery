# HellDelivery 진행 현황 — 빌드 48

2026-09-11 갱신. 1·2단계(빌라 협동 기준선/온라인 기반)에 이어 사용자가 승인한 3·4단계(차량/전체 배송/성공·실패·평가)를 통합했다. 빌드 48의 최종 검증·전달 상태는 WINDOWS_PLAYTEST_48.md를 따른다. 실제 여러 PC와 외부망 검증은 로컬 자동 검사와 분리한다.

## 현재 위치
물류센터에서 택배를 직접 싣고 트럭을 운전해 빌라로 이동한 뒤 주소별 배송과 평가를 받는 1~4인 Windows 테스트 게임이다. 성공/부분 실패/시간 초과/차량 파손에서 결과→재도전/다음 주문으로 이어진다. 일반→혼합→공동 운반의 3연속 코스도 제공한다. 코스는 같은 물류센터·빌라의 주문 구성을 바꾸며 서로 다른 맵 3개가 아니다. 점수는 방 기록이며 영구 경제·성장/Steam 출시 완료는 아니다.

## 구현된 기능
| 영역 | 현재 구현 |
|---|---|
| 캐릭터 | 이동/달리기/점프/1인칭 시점, 기존 캐릭터 선택, 이동·운반 모션, 머리 상하 시선 추종 |
| 물리 운반 | 잡기/놓기/스윙으로 던지기, 무게 차이, 공동 잡기, 충돌·밀기·차단 시 해제 |
| 차량·물류센터 | 실제 적재/문·경사로/4개 좌석/운전자 교대/힘 기반 운전·후진·제동/하역, 약 60m의 연속 도로, 독립 물리 화물과 열린 문 낙하 |
| 배송 평가 | 제한 시간, 택배 파손·분실/차량 손상, 성공·부분 실패·시간 초과·차량 운행 불가, S/A/B/C/F 및 점수, 방 최근 기록 |
| 대표 맵 | 빌라 외부와 지면/주차장/트럭 외형, 현관/실내 계단/2층 201·202호, 주소·동선 안내, 기존 제공 에셋 활용 |
| 게임 모드 | 전체 배송 1~4인, 기존 빌라 온라인 2~4인 연습/싱글/로컬 2인 분할 화면. 차량·평가는 전체 배송 모드에 적용 |
| 온라인 | 방 만들기/IP 참가, 네 자리 캐릭터 미리보기/선택/전원 준비, 참가자별 입력 지연 시 개별 정지, 호스트 권위 플레이어·택배·배송 동기화, 로딩/응답 지연/끊김/재참가 처리 |
| 주문 | 일반 15kg 2개, 다건 15kg 4개, 공동 운반 45kg 2개, 혼합 15kg 2개+45kg 1개 |
| 배송 판정 | 주소별 목표 수, 오배송 거부, HUD·목록·완료 판정 일치, 실제 배송 수와 시간 결과 |
| 연속 진행 | 정상 완료/합의한 부분 종료, 같은 방 다음 주문, 3연속 코스(일반→혼합→공동, 총 7개)와 합산 결과 |
| 협동 안내 | 동료 위치/거리/방향, Tab 택배 목록, G 잡은 택배 운반 도움 요청/취소·합류 시 자동 종료 |
| 복구 | 개인 위치 복구, 호스트 전체 복구/재시작, 완료한 배송 유지 |
| UI·환경 | 메인 메뉴/일시정지/조작법/첫 안내, FOV·감도·화면·음량·그림자 설정과 저장, 기본 효과음 |
| 기록·전달 | 방 누적 실적/최근 5건, 코스 진행 보존 및 재접속 전달, Windows 실행 ZIP·라이선스·로그·해시 |

방 기록과 코스 진행은 호스트 방이 유지되는 동안의 기록이다. 영구 진행 저장/경제 시스템은 아니다. 트럭은 전체 배송 모드에서 운전 가능하며 기존 빌라 연습에서는 외형 배치를 유지한다. 캐릭터 선택은 꾸미기·구매·성장 시스템과 구분한다. 현재 온라인 정원은 4명이며 Steam 친구 초대/자동 중계는 없다.

## 검증과 남은 문제
- 빌드 48: 최종 Windows 검사 662개 통과. 1인 51 + 2인 직접 적재/하역·202호 계단 배송 112 + 4인 전체 배송 151 + 기존 빌라 4인 150 + 일반 렌더링 회귀 198. 문 낙하·실제 충격·정상/부분 실패·시간/차량 실패·복구·다음 주문/코스를 확인했다. 패키지와 한계는 WINDOWS_PLAYTEST_48.md를 따른다.
- 빌드 47 최종 자동 검사: 2인 전체·운반 반복 520 + 4인 150 + 2인 코스 144 + 일반 회귀 197 = 1,011개 통과. Windows export와 실제 렌더링 캡처 검토 완료. ZIP 해제본 148개 파일 해시 일치와 180프레임 실행 확인. 전달 위치/해시는 WINDOWS_PLAYTEST_47.md를 따른다.
- 재현된 계단 해제는 가상 운반 목표점과 표면 부착점 대신 실제 시점→택배 중심으로 차단을 확인하도록 수정했다. 최종 한 실행에서 네트워크 입력으로 202호 전체 계단 운반 4회 연속 통과. 힘/무게/충돌은 유지한다.
- 4인 독립 이동/공동 잡기/개인 복구/도움 요청/전원 종료 합의, 한 명의 지연만 정지, 3인 진행과 중간 슬롯 퇴장/재참가, 배송 중 새 참가 거절, 3연속 코스를 로컬 실제 Windows 프로세스 간 ENet으로 검사했다.
- 과거 사용자 확인은 기본 빌라 클리어/동선/실내·캐릭터·설정 및 일부 온라인 연결이다. 최신 네 주문과 3연속 코스를 2~4명이 실제 여러 PC에서 운반하는 확인은 아직 남았다.
- 코스/주문 판정 검사 일부는 목적지에 택배를 배치한 fixture다. 모든 택배를 사람이 계단으로 운반한 검증과 다르다.
- 외부망·손실/고지연·장시간·다른 PC/GPU 성능은 미검증이다. 호스트 이전/Steam 중계는 미구현이다. 실제 45kg 공동 적재 전 구간과 운전/평가 밸런스는 사람이 확인할 항목이다.
- 빌드 번호나 검사 수를 전체 게임 완성도 백분율로 환산하지 않는다.

## 아직 구현되지 않은 주요 기획
1. 온라인 2~4인의 실제 여러 PC·외부망·장시간 성능 검증. 기능 구현과 로컬 다중 프로세스 검증은 빌드 47에 포함하며 아래 검증 기록을 기준으로 판단한다.
2. 차량 기울기/전복·서스펜션/정교한 운전 애니메이션, 더 긴 운송 경로와 차량 종류. 현재는 기울기를 잠근 아케이드 차량 1종이다.
3. 평가·제한 시간·충격 임계값의 실제 협동 밸런스 조정과 점수의 보상 사용처. 현재 점수는 방 기록용이다.
4. TV/냉장고/풍선 박스/동물/위험물 등 특수 택배, 다른 정식 배송 지역, 환경 장애물·이벤트.
5. 장비, 외형 해금/경제·성장, 영구 진행 저장. 세부 아이템은 기획 후보 전체를 한 번에 구현하는 범위가 아니다.
6. Steamworks/친구 초대/업적/배포, 출시용 최적화·호환성·사운드·아트 마감.

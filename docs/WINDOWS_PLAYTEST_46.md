진행 중 같은 주문 재시작은 해당 순서를 다시 시작한다. 완료된 코스 순서는 결과에서 재시작할 수 없어 중복 집계를 막는다. 부분 배송 합의 종료는 남은 순서를 진행하지 않고 실제 실적으로 코스를 종료한다. 연결 중단은 현재 미완료 주문을 새로 시작하되 완료한 이전 순서의 실적은 유지한다. 호스트 방에 재참가하면 현재 코스와 실적을 다시 받는다. 호스트 방 종료는 모두 초기화한다.

대기실에서 다른 주문을 고르면 코스를 종료하고 양쪽 준비를 해제한다. 완료한 개별 주문은 방 기록에 남는다. 코스를 모두 마치거나 부분 종료 후 대기실로 돌아오면 일반 주문 선택 상태이며 다시 코스를 고를 수 있다. 기존 물리/맵/에셋을 사용한다. 프로토콜 46, 양쪽 같은 빌드 필요. commit/push 없음.

# Windows 플레이 테스트 27 — 온라인 연결 상태·취소

사용자 요청: 실제 두 PC 테스트는 나중에 하고 다음 구현 진행. 빌드 26의 실제 LAN/인터넷 플레이는 미검증으로 유지한다.

## 변경

- 참가자에 1초 간격의 실제 ping/pong 왕복 시간(ms) 표시. 세대/송신 권한/미응답 토큰을 확인하고 5초 지난 토큰은 제거한다. 150ms 이상은 반응 지연 가능 안내. RTT는 인터넷 보장값이 아니라 현재 세션의 왕복 측정값이다.
- 호스트는 0.5초간 입력 수신이 없으면 상대 입력 지연·안전 정지 안내, 참가자는 0.5초간 상태 수신이 없으면 상태 수신 지연 안내. 기존 호스트 중립 입력 처리를 유지한다.
- 방 대기/접속 중 취소 버튼으로 소켓을 정리하고 IP/포트 입력 화면으로 돌아온다.
- 상태 수신 타임아웃 후 연결 종료 처리한 같은 프레임에서 연결 HUD를 다시 덮어쓰던 흐름을 return으로 종료했다.
- 캐릭터/맵/물리/배송 규칙 변경 없음. 기존 미커밋/빌드 보존, commit/push/공개 배포 없음.

## 검증 방법/한계

실제 Windows 두 프로세스 loopback 연결로 ping 응답을 확인한다. 참가자 세션의 입력 송신 처리를 잠시 멈춰 호스트 지연 안내/중립 입력을 검사하고 재개 후 연결 유지 여부를 확인한다. 이는 실제 네트워크 패킷 손실/지연 주입 시험이 아니다.
기존 공동 운반, 참가자 202호 계단 경로, 완료/재시작/재접속/호스트 종료를 함께 검사한다. 별도 회귀에서 온라인 대기 취소와 메뉴 복귀를 확인한다.
실제 두 PC/인터넷/장시간은 미검증이며 사용자가 나중에 테스트한다. 참가자 위치 예측과 Steam 중계는 아직 없다.

사용자가 현재 빌라 기준 빌드 확인 후 제안한 협동 통합을 승인했다. 기존 LocalCoopTest의 분할 화면/공유 물리/캐릭터 예약을 빌라 두 집 배송에 통합했다. 온라인은 후속이며 이번 빌드는 같은 PC의 키보드·마우스 P1 + 게임패드 P2 조합이다.

## 구현

- 메인 메뉴의 빌라 협동 · 2인 분할 화면에서 진입한다. 각자 다른 캐릭터를 확인해야 게임이 시작한다. 선택 중 물리/타이머를 멈추고 뒤로로 메뉴에 복귀할 수 있다. 마우스 또는 각 입력장치의 방향키/확정 입력을 사용한다.
- 하나의 빌라 월드를 두 SubViewport가 공유한다. P1/P2 각 시점·조준점·협동 운반 표시와 공통 배송 HUD를 제공한다. 미리보기 월드는 분리해 조명이 빌라로 새지 않게 했다.
- P2의 계단 충돌 마스크/예외를 P1과 맞췄다. 두 사람 복구·P2 낙하 복구, 공유 배송 2개 완료·재시작·메뉴를 연결했다.
- P2의 장치별 X 점프/L3 달리기를 추가했다. RT/A 잡기와 스틱 이동/시점은 기존 구현을 사용한다. 게임 중 공통 메뉴/복구/재시작은 P1 Esc/F5/R.
- PauseMenu는 루트가 아닌 소속 레벨의 HUD/복구를 사용해 중첩된 협동 레벨에서도 동작한다. 싱글 메뉴/콘텐츠는 유지한다.

## 검증과 발견한 수정

Windows EXE/PCK를 사용한다. 합성 게임패드/마우스 입력 검사는 실물 패드 또는 두 사람 직접 플레이와 다르다. 물건 배치/직접 grab 연결 검사는 판정/협동 물리 fixture이며 실제 입력 운반 검사가 아니다.

BuildCoopVisual: 캐릭터 선택/중복 방지, 공유 월드, P1 마우스·P2 이동/트리거/점프 독립성, P2 낙하 복구, 두 사람 동일 상자 연결/한 사람 놓기, 공유 배송·복구·완료·재시작·메뉴를 검사한다. 이어 P2가 출발 택배를 트리거로 잡고 이동 스틱 입력과 자동 시점 조절로 골목·계단을 거쳐 202호에 배송한다. 이 경로에는 플레이어/택배 순간이동이나 직접 배송 호출이 없다. P1은 출발 위치에 남는다. 두 사람 동시 왕복을 자동 운반했다고 주장하지 않는다.

수정: 상속 씬 안 P2 추가가 로드되지 않아 빌라 협동 레벨이 직접 생성하도록 바꿨다. P2 계단 보행용 충돌 레이어 누락을 실제 운반에서 재현해 수정했다. 미리보기 광원이 공유 월드에 영향을 주는 것을 화면에서 확인해 분리했다. 검증 스크립트가 한 프레임에 같은 합성 이벤트를 재사용한 경고는 이벤트 복제 방식으로 수정했다. 오류/경고를 통과 처리하지 않았다.

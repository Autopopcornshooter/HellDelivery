# 현재 빌라 Windows 테스트 빌드 점검

## 현재 후속 단계: 빌라 로컬 협동
사용자가 villa-18 검증 후 제안한 협동 통합을 승인했다. villa-19는 키보드·마우스+게임패드 2인 분할 화면 테스트 빌드다. 아래는 싱글플레이 기준선 기록으로 유지하며, 협동 최신 상태는 WINDOWS_PLAYTEST_24.md를 기준으로 한다. 온라인은 이번 범위가 아니다.

최신: WINDOWS_PLAYTEST_18.md. 과거 빌드별 이력은 WINDOWS_PLAYTEST.md 및 WINDOWS_PLAYTEST_02~16.md를 참고한다. 기존 문서의 오래된 미구현 서술보다 실제 로컬 구현과 최신 보고서를 우선한다.

| 항목 | 상태 |
|---|---|
| 기본 이동·운반·달리기 팔 | 사용자 확인 완료 |
| 캐릭터·제공 환경 에셋·트럭·지면·빌라 실내 | 사용자 피드백 반영 및 확인 |
| 201/202 주소 가독성·두 집 왕복 | villa-14 사용자 확인 |
| HUD 문장 폭에 맞는 배경 | villa-16 사용자 확인 |
| 배송 판정·복구·재시작·메뉴 복귀 | Windows 자동 회귀 검증 |
| 설정 유지·모델 포함 | 사용자 확인 및 이전 빌드 자동 검사 |
| 일시정지 배송 현황·복구 버튼·HUD 겹침 정리 | villa-17 사용자 확인 완료 |
| Windows 패키지 | 각 빌드 로컬 export·별도 압축 해제 실행 검사 |
| 다른 PC/GPU·장시간 실행 | 미검증 |
| 기본 오디오 | 구현·이벤트 검증, 청취 품질 승인과 구분 |

현재 빌라를 처음부터 끝까지 플레이하는 목표와 접수된 마감 피드백은 확인 완료다. villa-18을 현재 맵 완성 기준 빌드로 유지한다. 온라인 협동·차량 운전·새 레벨·공개 Steam 데모 전체 완료를 뜻하지 않는다. 일반적인 다음 지시는 현재 맵 범위에서 진행한다. 다음은 새로 발견되는 결함 수정과 실제 다른 PC 검증이다. 새 개발 단계로 넘어가려면 협동·운전·새 맵 중 다음 목표를 명시해서 범위를 정한다.

## 협동 인수 현황 (villa-24)

| 항목 | 확인 범위 |
|---|---|
| 모델 방향·머리 상하 추종 | villa-20/21 사용자 확인 |
| P1/P2 동작 소리 | villa-23 사용자 문제없음 확인 |
| 두 사람 선택·공유 배송·계단 운반·완료 | Windows 자동 합성 입력 검사 |
| 패드 분리/재연결 | 콜백 자동 검사, 실물 재연결은 미검증 |
| 반복 세션 상태/해제 | villa-24 12회 검사, 최종 결과는 해당 보고서 참조 |
| 분할 화면 성능 | villa-23 이 PC 720p 고정 시점 네 표본, 다른 PC/장시간 미검증 |

새 콘텐츠 없이 현재 빌라 협동 기준선을 고정한다. 검사 실행 여부/결과는 WINDOWS_PLAYTEST_24.md에서 확인한다.
## 승인된 온라인 첫 빌드 (villa-26)
사용자가 온라인 2인 범위를 명시 승인했다. OnlineSession IP 직접 접속/호스트 권위 물리·공동 운반·배송·재시작·연결 종료를 구현했다. 내보낸 Windows 두 프로세스 loopback 검증을 수행하며 상세 최종 결과는 WINDOWS_PLAYTEST_26.md. 실제 두 PC/LAN/인터넷·지연/손실은 사용자 검증 대기다. 기존 싱글/로컬 협동 기준선은 유지한다.
